= Configure o NetApp Volume Caching
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para usar o cache de volume, execute algumas etapas para configurá-lo.

* Análiselink:../get-started/cache-prerequisites.html["pré-requisitos"] para garantir que seu ambiente esteja pronto.
* Crie um agente do Console.
* Criar sistemas que suportem o cache de volume.




[[create-a-console-agent-in-the-netapp-console]]
== Crie um agente de console no NetApp Console

A próxima etapa é criar um agente de console no NetApp Console.

Para criar um agente do Console antes de usar o Volume Caching, consulte a documentação do NetApp Console para link:https://docs.netapp.com/us-en/console-setup-admin/concept-agents.html#what-a-console-agent-does["Agentes de console"^].



[[create-systems]]
== Criar sistemas

Se você ainda não fez isso, precisa criar os sistemas para a origem e o destino.

* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-otc-aws.html["Inicie o Cloud Volumes ONTAP na AWS"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-otc-azure.html["Inicie o Cloud Volumes ONTAP no Azure"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-gcp.html["Inicie o Cloud Volumes ONTAP na GCP"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-adding-systems.html["Adicionar sistemas Cloud Volumes ONTAP existentes"^]
* https://docs.netapp.com/us-en/cloud-manager-ontap-onprem/task-discovering-ontap.html["Descubra os clusters ONTAP"^]
